Raysid for Garmin 1.3, build 91: the same app as in the Connect IQ Store, now for 48 Garmin watches.

## What's new since build 89

- Builds for 48 watch models (fēnix 6 Pro to fēnix 9, epix 2, Enduro 3 and 4, Forerunner 70/165/255/265/570/955/965/970, Instinct 3 AMOLED, MARQ 2)
- The Žhavá místa API key can be entered in the phone app settings and stays readable while typing
- Sharper launcher icon in the right size for each watch
- Contact e-mail in About: cenek@zhavamista.cz

Only the fēnix 7X Pro has been tested on a real watch. The other models are checked in the Connect IQ simulator; the layout adapts to the screen size. Feedback is welcome in GitHub issues or on the [Žhavá místa](https://zhavamista.cz) community Discord.

## Download

Download only the file for your watch. Install by copying the `.prg` into `GARMIN/APPS` on the watch over USB, see the [user guide](https://github.com/Vit882/Raysid-for-Garmin-/blob/main/docs/USER-GUIDE.md) ([Česky](https://github.com/Vit882/Raysid-for-Garmin-/blob/main/docs/USER-GUIDE-CS.md), [Polski](https://github.com/Vit882/Raysid-for-Garmin-/blob/main/docs/USER-GUIDE-PL.md)).
